## A Genuinely Free Option Most Eligible Filers Never Try

**IRS Free File** is a public-private partnership between the IRS and several tax software companies that lets eligible taxpayers file federal returns — and in many cases state returns — at no cost, through the same type of guided interview most paid tax software uses.

## Who Qualifies

For the 2025 tax year, IRS Free File is available to taxpayers with **Adjusted Gross Income of $84,000 or less** (threshold adjusts slightly year to year). Each participating software provider sets its own specific eligibility rules within that cap — some restrict by age, state residency, or military status — so the IRS's Free File site matches you to providers you actually qualify for rather than having you guess.

## Free File vs. Direct File vs. "Free Edition" Upsells

These are three different things, frequently confused:

| Program | What It Is |
|---|---|
| **IRS Free File** | Official partnership — guided software from approved providers, genuinely free for eligible filers |
| **IRS Direct File** | A separate IRS-run tool (where available in participating states) for filing directly with the IRS, no third-party software |
| **"Free Edition" from a tax software company** | Marketed free tier that often excludes common situations (itemizing, self-employment, investment income) and upsells you to a paid tier mid-filing |

The key distinction: accessing a company's "free" product by going directly to their website, rather than through the official IRS Free File portal, frequently does **not** guarantee the no-cost outcome — several major providers have settled with regulators over this exact pattern.

## How to Actually Use It

1. Go to the official IRS Free File lookup tool on irs.gov
2. Answer a few questions (income, age, state) to see which partner products you qualify for
3. Click through to the partner's site **from the IRS page** — this link is what guarantees the free offer applies
4. File both federal and, if the provider supports it, your state return

## What It Covers

Most Free File software supports W-2 income, interest and dividend income, unemployment compensation, Social Security income, the standard deduction, itemized deductions, and common credits like the EITC and Child Tax Credit. Self-employment income, rental income, and more complex investment situations are usually still supported but vary by provider — check before starting.

## Fillable Forms for Any Income Level

If your AGI exceeds the Free File threshold, the IRS also offers **Free File Fillable Forms** — electronic versions of the actual paper forms with basic math checking, but no guided interview or error-checking beyond arithmetic. It's free for any income level, but best suited to filers comfortable preparing their own return without software guidance.
